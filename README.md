# 🤖 AI CEO

## Local AI Mathematics, Geometry & Study Assistant

AI CEO is a local AI-powered study assistant designed to help students with mathematics, geometry, and step-by-step problem solving.

---

## 🚀 Features

- 🧮 Mathematics tutoring
- 📐 Geometry problem solving
- 📷 Image-based question solving
- 📝 Step-by-step explanations
- 💬 Chat history
- ➕ New Chat
- ✏️ Rename Chat
- 🗑️ Delete Chat
- 📤 Upload images
- ❌ Remove images
- 🧠 Local AI with Ollama
- 🐍 Python source code
- 🔧 Easy to customize

---

## 🖥️ Requirements

- macOS
- Python 3
- Ollama
- Compatible Ollama AI model

---

## 🛠️ Installation

### 1. Install Python

Install Python 3 on your Mac.

### 2. Install Ollama

Install Ollama separately.

### 3. Download a compatible Ollama model

Choose an Ollama model compatible with your computer.

### 4. Download the AI CEO source code

The complete source code is provided to customers after purchase.

### 5. Install required packages

```bash
pip install -r requirements.txt
```

### 6. Run AI CEO

```bash
python study_assistant.py
```
