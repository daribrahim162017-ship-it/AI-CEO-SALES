# 🤖 AI CEO

### Local AI Mathematics, Geometry & Study Assistant

AI CEO is a local AI-powered study assistant designed to help students with mathematics, geometry, and step-by-step problem solving.

## 🚀 Features

- 🧮 Mathematics tutoring
- 📐 Geometry problem solving
- 📷 Image-based question solving
- 📝 Step-by-step explanations
- 💬 Chat history
- ➕ New Chat
- ✏️ Rename Chat
- 🗑️ Delete Chat
- 📤 Upload images
- ❌ Remove images
- 🧠 Local AI with Ollama
- 🐍 Python source code
- 🔧 Easy to customize

## 📚 Mathematics & Geometry

AI CEO includes dedicated modules for:

- Angles
- Triangles
- Circles
- Polygons
- Coordinates
- Trigonometry
- Algebra
- Arithmetic
- Ratios
- Geometry checking
- Geometry engines
- Image-based geometry processing

## 🖥️ Requirements

- macOS
- Python 3
- Ollama
- Compatible Ollama AI model

## ⚡ Why AI CEO?

AI CEO runs locally with Ollama, allowing developers to customize the application and its mathematics/geometry logic.

## 🛠️ Installation

1. Install Python 3.
2. Install Ollama.
3. Download a compatible Ollama model.
4. Download the AI CEO source code.
5. Install the required Python packages.
6. Run the application.
